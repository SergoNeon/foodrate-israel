# FoodRate Israel

Independent trilingual food and restaurant discovery prototype for Israel.

## Pages
- index.html — home/discovery
- search.html — search + city/kosher filters
- city.html?id=tel-aviv — city page
- restaurant.html?id=shuk-grill — restaurant profile

## Features
- Hebrew / Russian / English
- Full RTL support for Hebrew
- Persistent language choice
- Search and filtering
- Restaurant source-rating comparison
- Dish-level ratings
- Reviews section
- Responsive mobile layout

## Data policy
All venue names, addresses, reviews, counts and ratings currently included in the prototype are demo/sample data. Production data must be replaced with licensed, authorized, official API, partner, or open-data sources with required attribution.

Stage 2 prototype.
