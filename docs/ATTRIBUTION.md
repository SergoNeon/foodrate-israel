# Attribution and source provenance

FoodRate Israel keeps source provenance per record.

## OpenStreetMap
When OpenStreetMap-derived data is displayed publicly, show:

**© OpenStreetMap contributors**

and a link to the OpenStreetMap copyright / ODbL page.

OSM-derived records remain source-scoped so their provenance can be identified and ODbL obligations can be satisfied without incorrectly attributing unrelated data.

## Government open data
For data.gov.il sources, keep:
- dataset ID
- resource ID
- publisher
- license string
- fetched_at
- source URL

## Commercial APIs
Do not merge or republish fields beyond what each provider's current terms permit. Keep provider IDs and attribution separately.
